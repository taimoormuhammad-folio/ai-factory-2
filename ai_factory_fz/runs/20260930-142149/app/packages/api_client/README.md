# api_client (EXPERIMENTAL)
Contract for the lighting e-commerce app. In the Speed Demo MVP (M1) the Flutter app uses a bundled mock catalog and calls no endpoints; the only operation is the infrastructure health check. The catalog component schemas define the exact shape of the bundled mock catalog JSON (root schema MockCatalog) and of future catalog responses, so the mock can be replaced by a generated dart-dio client without changing app models. All money values are integer minor units (cents) with an ISO 4217 currency code; floating-point money is never used. Errors use the shared Error schema. List endpoints (future) paginate with page and pageSize and return items and total.
