# api_client (EXPERIMENTAL)
Womens Jewellery e-commerce API contract for the M1 Speed Demo and later milestones.
M1 Flutter app uses local mock data only and does not call this API.
This document covers must-have catalog stories (US-001 browse, US-002 detail):
health probe plus two public catalog read operations. Cart is in-memory on
the client in M1 (US-003) and has no API operations here. Auth, payments,
checkout, and orders are deferred. Reviews are read-only on product detail;
verified-purchase write path is deferred.
